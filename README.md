# Habit Tracker CLI App

A command-line habit tracking application built in Python using Object-Oriented and Functional Programming concepts.

Developed as part of the IU course:
Object-Oriented and Functional Programming with Python (DLBDSOOFPP01)

## Project Overview

This application allows users to:

- Add and manage daily/weekly habits
- Mark habits as completed
- Analyze habits using pure functions
- Save and load habit data persistently via JSON

## How to Run

1. Clone the repository:


2. Run the application:

```bash
python cli.py
```

## Key Concepts

- Object-Oriented Programming:
  - Habit and HabitManager classes
- Functional Programming:
  - Analytics module with pure functions
- Persistent storage:
  - JSON-based
- Command-line interaction:
  - input()-based CLI

## Testing

Unit tests are written using pytest and cover:

- Habit creation and streaks
- Analytics functions
- Habit management operations

To run tests:

```bash
python -m pytest
```
